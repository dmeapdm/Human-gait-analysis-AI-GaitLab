Human Gait Analysis System (Computer Vision & AI)
Project Overview
This project is a real-time biomechanical analysis engine developed to capture and process clinical data using Python 
and synchronized camera feeds. It focuses on high-precision tracking of human gait milestones for rehabilitation analysis.

Development Methodology: AI-Assisted Iterative Orchestration
Leveraging my background in Medical Physics (Balseiro Institute), I utilized a Human-in-the-loop (HITL) approach to accelerate development. 
I acted as a technical architect, guiding AI models through natural language requirements and engineering feedback to reach a stable version.

Key Milestones in v5.0:
Iterative Refinement: Reached the current stable version through 5 major iterations, personally validating logic against physical biomechanical constants.

Computer Vision Pipeline: Implemented multi-camera synchronization and landmark detection for precise movement tracking.

Quality Assurance: Personally debugged AI-generated blocks to ensure 100% data integrity in the analytical output.

Technical Stack
Language: Python (MediaPipe, OpenCV, NumPy, Matplotlib)

Workflow: AI-Assisted Development (Vibe Coding / Iterative Prototyping)

Future Roadmap
OT Integration: Upcoming integration with Arduino-based sensors (MMA7361) for hybrid physical-digital data acquisition.

ML Inference: Deployment of specialized gait-correction models.
